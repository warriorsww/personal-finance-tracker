# Personal Finance Tracker

A data analytics project built to track personal income, 
expenses, and savings goals using SQL and Tableau.

## Tools Used
- SQL (data storage and querying)
- Tableau Public (data visualization)
- Python (data cleaning)

## Features
- Log and categorize income and expenses
- Query monthly spending summaries using SQL
- Visualize spending breakdown with an interactive 
  Tableau dashboard
